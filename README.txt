3DSHOP - WEB PARA GITHUB PAGES

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En Settings > Pages, selecciona Deploy from a branch y la rama principal, carpeta /root.
3. Guarda y espera a que GitHub Pages publique la web.
4. Cuando tengas la URL definitiva (github.io o dominio propio), puedes añadir un sitemap.xml con esa URL como base.

SEO incluido:
- title y meta description
- robots index/follow
- Open Graph básico
- headings semánticos
- textos descriptivos y alt en imágenes
- datos estructurados Organization
